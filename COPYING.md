# Licensing and upstream attribution

This is a collection of porting work across multiple projects, not a single-license
distribution. Existing SPDX identifiers and copyright notices are retained.
Kernel drivers/patches, libcamera changes, libfprint changes and other components
carry their respective file-level or upstream terms. A patch does not replace
the license of the project it modifies.

Examples include GPL-2.0 kernel files, GPL-2.0-or-later camera components,
LGPL-2.1-or-later libfprint components, MIT native helpers, and
BSD-3-Clause-Clear UFS/RPMB code. Consult each file and its upstream source.
The upstream projects and pinned references are listed in
[development notes](docs/DEVELOPMENT.md).

No new blanket license is assigned by this initial publication. Files without
an explicit license require clarification before reuse; do not assume that
public availability supplies a license. A comprehensive license manifest remains
release work. No proprietary vendor firmware, binaries or calibration data are
distributed by this repository.

Razer, Kali, NetHunter and other project names identify compatible hardware and
upstream software; this repository does not claim their endorsement.
